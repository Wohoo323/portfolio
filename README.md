## About the Project

This portfolio was created as a personal website for presenting my skills, studies and software development projects.

The website is developed locally using WordPress and a custom child theme based on the Twenty Twenty-Five theme.

The goal of the project was not only to create a portfolio, but also to learn more about WordPress development, custom themes, responsive web design and website deployment.

## WordPress Theme

The portfolio uses a custom WordPress child theme.

The repository contains the main custom theme files:

- `style.css` – custom styling and responsive design
- `script.js` – animations and interactive functionality
- `functions.php` – WordPress theme configuration and asset loading

## Deployment

The WordPress website is developed locally using Local.

The production website is deployed as a static website:

WordPress (Local)  
→ Simply Static  
→ Static HTML/CSS/JavaScript export  
→ Netlify  
→ Custom domain

This allows WordPress to be used as the local content management system while the public website is served as a fast static website through Netlify.

## Updating the Website

When changes are needed:

1. Update the website in the local WordPress installation.
2. Generate a new static export using Simply Static.
3. Deploy the generated files to Netlify.
4. Netlify publishes the updated version to the custom domain.
